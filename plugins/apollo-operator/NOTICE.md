# Source and credit

Apollo Operator is an open-source headless GTM toolkit by Creatop, a B2B outbound agency. The MIT license is included.

This plugin adapts the Apollo Operator source at main@9bb7ec5, commit 9bb7ec5dded763dae85fc93d3bad3cb94bbac5db. Source: https://github.com/creatop-gtm/apollo-operator. The ChatGPT portable source is independently pinned by archive and member hashes; its release version is not assumed to match the Git source version.

It is not listed in OpenAI's public plugin directory; install it from this repo.
