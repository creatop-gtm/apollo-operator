# Source and credit

Apollo Operator is an open-source headless GTM toolkit by Creatop, a B2B outbound agency. The MIT license is included.

This plugin adapts the Apollo Operator source at main@94b6a93, commit 94b6a930d3fe81199749592264419128334a04ef. Source: https://github.com/creatop-gtm/apollo-operator. The ChatGPT portable source is independently pinned by archive and member hashes; its release version is not assumed to match the Git source version.

It is not listed in OpenAI's public plugin directory; install it from this repo.
