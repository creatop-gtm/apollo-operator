# Source and credit

Apollo Operator is an open-source headless GTM toolkit by Creatop, a B2B outbound agency. The MIT license is included.

This plugin adapts the Apollo Operator source at main@34f8950, commit 34f8950a3fb5e766d53afe935c410c772a18e08b. Source: https://github.com/creatop-gtm/apollo-operator. The ChatGPT portable source is independently pinned by archive and member hashes; its release version is not assumed to match the Git source version.

It is not listed in OpenAI's public plugin directory; install it from this repo.
